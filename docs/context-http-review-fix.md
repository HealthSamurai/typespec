# Исправление F1 после независимого HTTP review

Независимый отчёт по e6ec120: context-http-review.md. Review подтвердил устранение семи ложных ошибок, но нашёл регрессию результата пользовательских перегрузок. Этот документ фиксирует последующее исправление, не меняя исторический вывод reviewer.

## Исправлено

Выбор диагностической перегрузки отделён от доказательства возвращаемого типа. При отсутствии passing-кандидата и наличии непроверенной границы учитываются все incomplete и все nil-compatible кандидаты (в том числе с unknown после удаления nil). Если таких нет, для консервативного результата учитываются все fits. Различные результаты дают unknown, не тип последней отвергнутой перегрузки. Конкретные ошибки аргументов остаются. Nil-диагностики жизнеспособных альтернатив сохраняются отдельно: это консервативная граница, а не утверждение, что вызов обязательно упадёт.

Добавлены оба repro F1, callback positive/negative, три порядка трёх кандидатов с nil/unknown и строгий режим. F2 (текст предупреждения выбирает узкую перегрузку) намеренно не менялся; HTTP snapshot не переснимался.
