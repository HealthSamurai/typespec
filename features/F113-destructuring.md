# F113 · Деструктуризация

В Clojure параметры функций и `let` часто сразу разбирают входную структуру на локальные имена. Typespec переносит в эти имена типы из Spec и литералов, учитывает type hints и проверяет дальнейшее использование. Обязательность поля следует из типа мапы. Само связывание поля допускает его отсутствие.

## Мапы в Clojure 1.12.4

- `:keys`, `:ns/keys`, `:strs`, `:syms` и `:ns/syms` сохраняют вид и namespace ключа. Явные пары читают keyword, строковый или quoted symbol-ключ. Вложенные patterns получают тип выбранного поля.
- `s/keys` даёт типы keyword-полей, а `s/map-of` даёт тип значения для ключей подходящего вида. Литеральные мапы с такими ключами дают тип поля и факт его наличия. При передаче такой мапы в `s/map-of` проверяются ключи и значения.
- Вычисляемый селектор в форме `{value selector}` проверяется как выражение. Известный строковый, символьный или keyword-ключ читается как явный ключ. Для селектора с подходящим типом ключа `s/map-of` выводится тип значения с учётом возможного отсутствия поля.
- Если Spec или ветки выражения задают конечный набор таких ключей, чекер объединяет типы выбранных полей. `:or` входит в результат, если хотя бы один возможный ключ может отсутствовать. Записанный `nil` сохраняется.
- `:or` применяется при отсутствии ключа, в том числе при разборе `nil`. Присутствующий `nil` остаётся `nil`. Выражение default проверяется и для обязательного поля, а его тип добавляется только при возможном отсутствии поля.
- Для входной мапы `:as` связывает исходное значение. Обычные привязки без default могут участвовать в сужении остальных полей того же union по тесту или `case` на поле-теге.
- При разборе `ISeq` с известными позициями, например из `(list :n 2)`, `(seq [:n 2])` или `'(:n 2)`, пары образуют мапу, которую получает и `:as`. Последний повтор ключа побеждает, в том числе из завершающей мапы с известными ключами. Пустая последовательность даёт пустую мапу, а последовательность из одной мапы или `nil` передаёт её единственный элемент. Внутри `quote` списки и символы типизируются как данные.
- При конечном наборе возможных значений ключа чекер сохраняет возможные формы мапы, включая различия в наличии поля и его перезаписи. Если ключ неизвестен или комбинаций больше 256 для одного набора позиций, результат получает общий тип `map?`.
- Завершающий вектор из двух элементов добавляет пару и может перезаписать ключ, а пустая строка сохраняет собранную мапу. Известный недопустимый хвост, например число, непустая строка или вектор заведомо неверной длины, даёт `TSP2345` на map-шаблоне. Последовательности записей `Map.Entry` допускаются как хвост.
- Для параметра без контракта `:keys` даёт локальные сведения о читаемых keyword-полях. Типы строковых и символьных полей выводятся из известного входа.
- Порядок именованных привязок и вложенных map- и vector-шаблонов следует развёртке Clojure 1.12.4, когда их формы представлены обычными данными Clojure. Директивы `:keys`, `:strs` и `:syms` сначала расширяются в мапу привязок. `:or` и вычисляемые селекторы видят локальные имена, уже связанные в порядке обхода этой мапы. Директива может заменить селектор явной привязки к тому же имени.

## Пример

```clojure example
(ns example (:require [clojure.spec.alpha :as s]))

(s/fdef item-count :args (s/cat :counts (s/map-of string? int?)) :ret int?)
(defn item-count [{:strs [items] :or {items 0}}]
  (inc items))

(item-count {"items" 2})
(item-count {:items 2})

(let [{n :count :or {n 7}} nil]
  (inc n))

(let [{:syms [count] :or {count 7}} {'count nil}]
  (inc count))
```

```text output
8:13  TSP2345  {:items 2} is not assignable to (s/map-of string? int?)
14:8  TSP2531  count may be nil: count is nil?, and :or applies only when the key is absent
```

Тесты используют обычный `check-files`, проверяют контракт между namespaces, диагностики и исполнение контрольных форм на закреплённом Clojure. [destructuring_test.clj](../test/typespec/destructuring_test.clj)

## Векторы и оставшиеся случаи

`s/tuple` сохраняет позиции. Для коллекций с ограниченной длиной известные позиции получают тип элемента или `nil` по границам длины. Для обычной коллекции неизвестной длины возможный выход за пределы учитывается с `--strict-nil`. `:as` после `&` сохраняет тип исходного значения. [F330](F330-tuples-and-nonempty.md), [F331](F331-fixed-vector-positions.md)

Для полного статуса карточки остаются вывод формы мапы из последовательностей без известных позиций, порядок связывания для шаблонов с непрозрачными reader-формами и проверка формы на соответствие версии Clojure. Диагностика вложенного отсутствующего поля пока передаёт текстовую причину `nil`. Экспериментальные директивы Clojure 1.13 требуют сверки на отдельно закреплённой версии. [Reference](../docs/reference.md)
