# F233 · `comp` и `partial`

Чекер строит тип функции из сигнатур компонентов. Сигнатуры берутся из
обычных spec, type hints, `:t/sig` или EDN-деклараций. Получившуюся функцию
можно вызвать сразу, сохранить в `let` или передать как callback.

```clojure example
(ns example
  (:require [clojure.string :as str]))

(defn label-suffix
  {:t/sig '[int? :-> string?]}
  [index]
  ((partial subs "record") index))

(defn normalized-size
  {:t/sig '[string? :-> int?]}
  [value]
  ((comp inc count str/trim) value))

(mapv (partial subs "record") [0 1 2])
(mapv (comp byte int) "ABC")
```

```text output
(no diagnostics)
```

- `comp` проверяет стыки справа налево. Крайняя правая функция принимает
  аргументы вызова. Остальные должны принимать её результат или результат
  ближайшей функции справа как единственный аргумент. `(comp inc str)`
  даёт `TSP2345` на `inc`. Если промежуточная функция требует два
  аргумента, возникает `TSP2554`. При нескольких возможных результатах
  перегрузок сохраняется их объединение. Изменение мапы на промежуточном
  шаге уточняет форму по результату предыдущей функции. После смены
  результата исходные ключи остаются доступны только по контракту новой мапы.
- Ключевое слово в промежуточной позиции читает ключ из результата
  предыдущей функции по правилам обычного обращения к мапе. `first` и
  `second` используют известные позиции и длину последовательности.
  Литеральное множество возвращает найденное значение или `nil`.
- Когда `first` или `second` стоят справа, чекер проверяет следующие
  шаги по позиции в аргументе вызова. Это работает при прямом вызове,
  в `mapv` и `group-by`, а также при захвате коллекции через `partial`.
- Промежуточная функция с `t/all` решает ограничения по результату
  предыдущего шага. Это работает и после захвата аргументов через
  `partial`, если остался один параметр. Для `t/all` справа ограничения
  решаются по аргументам вызова композиции, а её следующие шаги проверяются
  по получившемуся типу.
- `partial` проверяет захваченные аргументы и сохраняет подходящие остаточные
  арности, включая нулевую и однородный `& rest`. У `(partial subs "record")`
  остаются арности с одним и двумя индексами. Когда функция сохраняет
  форму первого аргумента-мапы, `partial` вычисляет результат по
  захваченной мапе.
- Для `t/all` с одной фиксированной арностью `partial` сохраняет типы
  захваченных аргументов. Каждый вызов решает ограничения заново
  по захваченным и переданным аргументам. Дополнительный `partial`
  продолжает захватывать аргументы той же функции.
- Если фиксированная арность перекрывает вариативный минимум и
  отвергает захваченный аргумент, остаточная variadic-арность
  начинается со следующего числа аргументов.
- `(comp)` возвращает типизированную функцию identity. `(comp f)` и
  `(partial f)` сохраняют тип `f`. Известные выходные типы передаются
  непосредственным callbacks внутри `comp`. Известные параметры
  передаются callbacks, захваченным через `partial`.
- При неизвестной сигнатуре или неподдержанном
  переключении между фиксированной и variadic арностью чекер сообщает
  `TSP210-01`. Поддержка трансдьюсеров и динамического
  `(apply comp middleware)` остаётся в [F230](F230-generics-and-hof.md).

Пример приложения собирает функцию создания Todo из запроса к PostgreSQL
и формирования HTTP-ответа. Приёмочный прогон HTTP проверяет композицию
`(comp byte int)` при обходе строки. [Приложение](../examples/context-web-pg/README.md)
