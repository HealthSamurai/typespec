# F234 · Прямые `map` и `filter` в трёхаргументном `into`

В `(into target (map f) source)` чекер берёт тип элемента `source`,
проверяет, что его принимает `f`, и добавляет тип результата `f` к
типу элементов назначения. `filter` проверяет предикат и сужает
элементы с помощью существующих правил для проверенных guards.

`remove` сохраняет элементы, для которых предикат возвращает
`false` или `nil`. `take-while` выводит тип элементов, для
которых предикат истинен. `drop-while` сохраняет тип входа,
поскольку после первого ложного результата предиката проходят
все оставшиеся элементы. Если предикат истинен на всём входе,
`drop-while` не добавляет элементов.

В прямом `(into target (map-indexed f) source)` колбэк получает
индекс типа `int?` и элемент источника. Тип результата колбэка
передаётся в назначение. При заведомо пустом источнике вызов колбэка
не проверяется, а тип назначения сохраняется.

`keep` и `keep-indexed` исключают `nil` из результата колбэка
в прямом `into` и в `comp`. Значение `false` сохраняется. Для
`keep-indexed` первым аргументом колбэка служит индекс входного элемента.

`mapcat` добавляет элементы коллекции, возвращённой колбэком.
Результат `nil` даёт ноль элементов, а заведомо неподходящее
значение, например число, даёт `TSP2345` на колбэке.

Прямой `cat` разворачивает один уровень входных коллекций. Например,
`(into [] cat [[1] nil [2 3]])` выводит вектор целых чисел.

`take` и `drop` сохраняют тип входного элемента. Если вход может
дать элементы, чекер проверяет, что аргумент шага имеет тип
`number?`. `take` с неположительным числовым литералом не
добавляет элементов к назначению.

`(partition-all n)` передаёт в назначение непустые векторы элементов
источника, включая неполную последнюю группу. Положительная известная
ёмкость задаёт максимальную длину группы. Нулевая ёмкость даёт одну
группу для непустого входа. Чекер проверяет числовой аргумент и диапазон
известной ёмкости после преобразования к `long`.

```clojure example
(ns example (:require [clojure.spec.alpha :as s]))

(s/fdef labels :args (s/cat :xs (s/coll-of int?))
               :ret (s/coll-of string? :kind vector?))
(defn labels [xs] (into [] (map str) xs))

(into #{} (filter string?) ["a" 1])
(into [] (map inc) ["bad"])
```

```text output
8:15  TSP2345  inc takes number?, but gets string?
```

Когда источник заведомо пуст, прямые `map` и `filter` сохраняют
тип назначения. Если назначение содержит элементы, их типы
сохраняются вместе с типами новых значений. При записи в мапу
результат сохраняет тип `map?`. Вывод отдельных ключей из
произвольных пар остаётся за рамками этого правила.

Композицию этих шагов описывает [F235](F235-transducer-composition.md).
Вычисляемый или неподдержанный трансдьюсер получает `TSP210-01`.
При известном назначении вектор или множество сохраняют вид
коллекции и получают `t/unknown` для новых элементов.
