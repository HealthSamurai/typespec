# F270 · Операторы над типами мап

Полную запись, форму обновления и краткое представление можно строить из одного `s/keys`. Операторы доступны в цитированных `:t/sig` и внешних EDN-декларациях. Исходную форму и типы полей задаёт обычный Clojure Spec.

| Форма | Результат |
|---|---|
| `(t/pick T :k ...)` | Выбранные поля с исходными типами и обязательностью |
| `(t/omit T :k ...)` | Объявленные поля за вычетом указанных |
| `(t/partial T)` | Все поля верхнего уровня становятся необязательными |
| `(t/keys-of T)` | Объединение объявленных ключей, включая необязательные. Для пустой формы — `t/never` |
| `(t/get T :k)` | Тип чтения объявленного поля. Для необязательного поля добавляет `nil` |

## Пример

```clojure example
(ns example.operators
  (:require [clojure.spec.alpha :as s]))

(s/def ::id int?)
(s/def ::title string?)
(s/def ::note (s/nilable string?))
(s/def ::item (s/keys :req-un [::id ::title] :opt-un [::note]))

(defn brief
  {:t/sig '[::item :-> (t/pick ::item :id :note)]}
  [item]
  (select-keys item [:id :note]))

(defn patch-title
  {:t/sig '[(t/partial (t/omit ::item :id))
            :-> (t/get (t/partial ::item) :title)]}
  [patch]
  (:title patch))

(patch-title {})
(patch-title {:title "New title"})
(patch-title {:note nil})
```

```text output
(no diagnostics)
```

Пропущенный `:title` допустим в форме обновления. `{:title nil}` даёт `TSP2322`, поскольку тип сохранённого значения взят из `::title`. `:note` допускает `nil` по своему spec. Для `:req-un [::id]` ключ мапы — `:id`, а тип поля берётся из `::id`.

`t/omit` оставляет форму открытой. Например, функция с результатом `(t/omit ::item :id)` может вернуть исходный `item`, а для удаления данных нужна операция над значением. `t/keys-of` описывает объявленные ключи, поэтому runtime `keys` открытой мапы может вернуть и другие.

## Разрешение типов и диагностика

Разбор сохраняет оператор и его позицию. После сбора specs и EDN-деклараций Typespec разрешает форму мапы и проверяет литеральные ключи. Ссылки на типы полей сохраняются, в том числе рекурсивные. При печати сигнатуры сохраняется выражение оператора, чтобы его можно было прочитать повторно.

| Код | Причина |
|---|---|
| `TSP270-01` | Неверная арность оператора или ключ задан выражением |
| `TSP270-02` | Ключ отсутствует в форме, даже если для него есть отдельный spec |
| `TSP270-03` | Форма не сводится к одной явной `s/keys`, ключи конфликтуют, ссылка отсутствует, образует цикл или превышает лимит раскрытия |

Поддерживаются простые `:req`, `:opt`, `:req-un` и `:opt-un`, ссылки на такие формы и вложенные операторы. Объединения, nullable-мапы, пересечения, `s/merge`, `t/exact`, групповые требования ключей и параметр типа в качестве источника остаются за границей F270. Разрешение ограничено 256 шагами на оператор. Проверка выполняется над данными объявлений.
