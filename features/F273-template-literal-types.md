# F273 · Типы строковых шаблонов

## Мотивация и приоритет

Описывать ограниченные наборы строк, например имена событий; только при доказанной пользе для Clojure. Не заменяет runtime regex validation.

## Пример целевого поведения

```clojure
;; Требование, не новый Clojure-синтаксис:
;; EventName = "user/" + {"created", "deleted"}
;; => {"user/created", "user/deleted"}
;; Произвольный regex-предикат этим не доказывается.
```

Иллюстрация, не исполняемый тест и не утверждение о текущей реализации.

## Алгоритм и границы

1. В первом эксперименте разрешить только конечные наборы строковых литералов.
2. Вычислить произведение наборов и конкатенацию, сохраняя ограничение размера.
3. Проверять значения обычной совместимостью с literal union.
4. Для произвольных строк и бесконечных шаблонов не обещать точного разбора; отдельная задача исследования.
5. Не исполнять функции Clojure при построении типа.

## Критерии готовности и тесты

Конкатенация конечных наборов, пустая строка, недопустимый литерал, взрыв числа комбинаций и неизвестная часть шаблона.
