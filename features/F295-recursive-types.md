# F295 · Рекурсивные типы

Дерево можно описать обычными `s/def`, `s/keys` и `s/coll-of`.
`typespec check` проверяет аргументы и результаты функций по этим
схемам, в том числе когда схема, функция и вызов находятся в разных
namespace. Ошибка содержит путь до поля. Для вложенного литерала чекер
указывает позицию значения.

```clojure example
(ns example (:require [clojure.spec.alpha :as s]))

(s/def ::value int?)
(s/def ::children (s/coll-of ::node :kind vector?))
(s/def ::node (s/keys :req-un [::value ::children]))

(s/fdef consume :args (s/cat :node ::node) :ret ::node)
(defn consume [node] node)

(consume {:value 1 :children [{:value 2 :children []}]})
(consume {:value 1 :children [{:value "bad" :children []}]})
```

```text output
11:39  TSP2322  at [:children 0 :value]: "bad" is not assignable to int?
```

## Проверка

Чекер собирает определения всех namespace перед разбором циклов.
Через пустую коллекцию, `nil` или отсутствие необязательного поля можно
завершить конечное дерево. Два дерева с разными именами типов сравниваются
по структуре. При сравнении сохраняется направление совместимости.

Повторное структурное сравнение добавляет ребро к существующей паре типов.
Ошибки и незавершённые проверки распространяются по графу до получения
результата. Количество узлов и рёбер ограничено на одно сравнение.

| Диагностика | Значение |
|---|---|
| `TSP295-01` | Цикл ссылок без перехода через структуру, например `::a → ::b → ::a` |
| `TSP295-02` | У рекурсивной схемы отсутствует конечная база или её нельзя доказать |
| `TSP9003` | В определениях, связанных с рекурсивной схемой, обнаружена отсутствующая ссылка |
| `TSP210-01` c `recursive-budget` | Исчерпан бюджет сравнения |

Поддерживаются регулярные схемы из мап, коллекций, tuples и объединений.
Рекурсия через функции, `s/merge` и непрозрачные предикаты остаётся
частью, которую чекер может пометить как непроверенную. Для `t/satisfies`
действуют те же правила структурного сравнения.

Регрессии проверяют корректные и ошибочные деревья до глубины 100,
взаимную рекурсию, отсутствие обязательных полей, циклы alias и бюджет.
