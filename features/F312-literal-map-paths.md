# F312 · `get-in`, `assoc-in` и `update-in`

`get-in` добавляет default к типу результата только при возможном
отсутствии пути. `nil` в найденном последнем поле остаётся частью
типа результата. Промежуточный `nil` прерывает путь и даёт default.

```clojure example
(ns example (:require [clojure.spec.alpha :as s]))

(s/def ::count int?)
(s/def ::stats (s/keys :req [::count]))
(s/def ::state (s/keys :req [::stats]))

(s/fdef incremented :args (s/cat :state ::state) :ret int?)
(defn incremented [state]
  (-> state
      (update-in [::stats ::count] inc)
      (get-in [::stats ::count])))

(get-in (assoc-in {} [:stats :note] nil) [:stats :note] "absent")
```

```text output
(no diagnostics)
```

`assoc-in` и `update-in` восстанавливают форму вдоль непустого пути
из известных keyword и строковых ключей, включая путь из `s/tuple`.
Конечные множества ключей дают объединение возможных форм после записи.
Типы берутся из `s/keys` и выведенных форм мап. Записанные ключи становятся
обязательными. Литеральное значение сохраняет свой тип. Для отсутствующего или
равного `nil` контейнера создаётся промежуточная мапа. Колбэк `update-in`
получает старое значение с учётом `nil` при отсутствии поля. Остальные
ключи сохраняются. Запись через заведомо скалярный контейнер даёт
`TSP2339` в позиции ключа.

В `s/map-of` можно записывать по вычисляемому ключу типа `string?`
или `keyword?`. `update-in` передаёт колбэку тип старого значения
с учётом возможного отсутствия записи. Результат объединяет типы
существующих и записанных ключей и значений. Проверка get-ig покрывает
запись во вложенный индекс артефактов с двумя вычисляемыми ключами.

Путь чтения может включать строки и целые индексы. Для индексов
учитывается возможный выход за границы. В векторе пути `get-in`
вычисляемый ключ использует домен и тип значения `s/map-of` или
конечное множество известных ключей и индексов. Путь можно передать
целиком, когда его позиции известны из `s/tuple` или выведены из кода.
Проверка `http` покрывает типизированный путь и исходную функцию
`get-cookie` с контрактом на cookies. Путь без известных позиций
и запись по индексам возвращают `t/unknown`.
