# F313 · Сохранение формы мапы через именованные функции

Чекер выводит преобразование результата функции с одним простым
параметром и одним выражением из `assoc` и `dissoc` с литеральными
ключами. Операции могут быть вложены или записаны внутри `->`.
Требования из `s/keys` и `s/fdef` проверяются обычным способом.
После проверки вызова чекер применяет изменения к конкретной
форме мапы, сохраняя типы остальных полей.

```clojure example
(ns example (:require [clojure.spec.alpha :as s]))

(defn stamp [m]
  (-> m (assoc :version 1) (dissoc :temp)))

(s/fdef label :args (s/cat :id string?) :ret string?)
(defn label [id]
  (:name (stamp {:name id :version "old" :temp true})))
```

```text output
(no diagnostics)
```

У `stamp` поле `:name` сохраняет тип аргумента, `:version` получает
тип `int?`, а `:temp` отсутствует. Вычисляемые ключи и произвольные
тела функций используют обычный вывод типа. Если уточнённый
результат несовместим с объявленным типом, действует объявленный
контракт. Анализ работает с исходниками и не исполняет функцию.

`update-vals` проверяет колбэк на типах значений. Он сохраняет
обязательные и необязательные ключи из Spec. На JVM вектор остаётся
вектором, а `nil` даёт пустую мапу без вызова колбэка.
`update-keys` проверяет колбэк на типах ключей и сохраняет тип
значений. Для вектора колбэк получает числовые индексы.

`merge-with` сохраняет поля мап известной формы и проверяет
двухаргументный колбэк только для совпавших ключей.

`clojure.set/rename-keys` применяет известные переименования к
исходным полям. Обмен двух ключей сохраняет типы обоих значений.
`clojure.set/map-invert` меняет местами типы ключей и значений.
Если несколько полей дают один ключ результата, сохраняются все
возможные исходные ключи.
`clojure.set/project` переносит типы выбранных полей в элементы
множества. Число строк ограничено числом исходных строк.
`clojure.set/rename` применяет известное переименование к каждой
строке, сохраняя типы полей и верхнюю границу размера множества.
`clojure.set/select` проверяет предикат на элементах и сохраняет
тип множества. Если предикат доказанно принимает все элементы,
исходная коллекция сохраняется целиком.
`clojure.set/index` использует проекцию как тип ключа и выводит
непустое множество исходных строк в каждой группе.
