# F411 · `apply` с хвостом известной формы

`apply` объединяет явные аргументы и позиции последнего вектора.
Длина и типы могут прийти из литерала, `s/tuple` или локального
значения. [F330](F330-tuples-and-nonempty.md) также передаёт
точную длину однородной коллекции. `nil` и пустая последовательность в позиции хвоста
добавляют ноль аргументов.
Небольшой конечный диапазон длины проверяется для каждой допустимой
арности. Строковый литерал даёт по одному аргументу типа
`java.lang.Character` на каждый кодовый элемент UTF-16.
Для JVM-массива используется тип компонента и, когда известна,
длина массива. Элементы ссылочного массива могут содержать `nil`.
Известная мапа передаёт пары `Map.Entry` с типами ключей и значений.
Число записей определяет арность. Тип каждой позиции включает возможные записи.
Заведомо неподдерживаемый конечный JVM-класс хвоста даёт ошибку
перед проверкой арности целевой функции.

`apply` проверяет вызов известного ключевого слова с одним аргументом
или с аргументом и значением по умолчанию. Сохранённый по ключу
`nil` возвращается как есть. Default берётся для отсутствующего ключа.
Символ в позиции функции поддерживает тот же вызов по ключу.
Мапа в позиции функции принимает ключ и необязательное значение
по умолчанию. Тип известного поля сохраняется из Spec.
Множество принимает один аргумент и возвращает найденное значение
или `nil`. Для литерала проверяется точное членство, включая `false`.
Вектор принимает один целочисленный индекс и проверяет границы
после преобразования JVM в `int`. Известная позиция сохраняет точный тип.

`cons` сдвигает границы длины хвоста. При известной длине хвоста
`apply` проверяет добавленный элемент и позиции хвоста вместе.
`list*` сохраняет позиции всех явных аргументов и последней
коллекции. Вызов с одной коллекцией возвращает её `seq`.
`lazy-seq` передаёт границы и известные позиции успешного результата
тела, в том числе когда результат пуст. Само тело остаётся ленивым.
`vector` сохраняет тип каждой позиции при прямом вызове и через
`apply`, если позиции аргументов известны.
`apply list` также сохраняет позиции для последующего чтения
или следующего вызова `apply`.
`hash-map` строит поля из известных пар. Повторяющийся ключ
получает последнее значение, а ключ без пары даёт ошибку.

```clojure example
(ns example)

(apply subs "prefix" [1])
(apply subs ["prefix" "wrong"])
(apply subs ["prefix"])
```

```text output
4:23  TSP2345  "wrong" is not assignable to int?
5:1  TSP2554  apply subs expects 2 or 3 argument(s), got 1
```

Вызов переиспользует проверку фиксированных и variadic-сигнатур,
перегрузок и `t/all`. При объединённом типе хвоста чекер проверяет
каждую ветку известной длины и объединяет возвращаемые типы.
Для inline-функции и её локального имени каждая ветка передаёт в тело
свои типы параметров. Например, у хвоста `(if flag ["x" "y"] [1 2])`
проверка `(string? x)` в теле разделяет вызовы с двумя строками
и вызовы с двумя числами.
Ошибки аргументов указывают на элемент литерала либо на выражение
хвоста, если его позиции известны из типа.

Для однородного хвоста чекер учитывает гарантированный минимум
длины и проверяет каждую достижимую арность, включая вариативный
хвост. Например, `(apply + xs)` выводит `int?`, если Spec даёт
коллекцию целых, в том числе пустую. Результаты перегрузок
объединяются. Если тип хвоста или доступные сигнатуры не доказывают
допустимую арность, чекер возвращает `t/unknown` и выдаёт `TSP410-01`
для проверяемой цели. В строгом режиме эта диагностика также видна без
сигнатуры. Встроенные функции со специальным правилом без
вызываемой сигнатуры остаются непроверенными целями.
