# Сведение карточек: критерии ревью

Статус: результаты 40 авторов получены; редакционное сведение и выборочные проверки завершены. Детали и границы проверки — REVIEW-FINDINGS.md. Финальная техническая валидация идёт отдельным этапом.

## Для каждой карточки

- ID, filename и YAML согласованы; implementation подтверждён конкретными частями исходников, не желаемым дизайном.
- Примеры отделяют current от planned; ожидаемая ошибка не выдаётся за фактический вывод без запуска.
- Алгоритм определяет вход, представление типов/фактов, шаги, результат, диагностики и неподдержанные случаи.
- Пример корректного кода, ошибка и пограничный случай входят в матрицу тестов.
- Код Clojure размечен `clojure`, EDN — `edn`; иллюстрации не маскируются под исполняемые тесты.
- Новые диагностические номера обозначены proposed; действующие коды не переименованы в документации задним числом.

## Финальная проверка

После завершения авторов: проверить локальные ссылки, повторяющиеся ID, YAML и индекс; запустить тесты. Не обновлять golden-файлы только ради зелёного теста. Изменения индекса вследствие уточнения статуса проверить отдельно. Полный обзор нельзя закрывать до чтения результатов всех 40 карточек. arXiv-отчёт — дополнительный источник, не замена этой проверке.
